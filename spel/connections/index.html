Connections Övning

Sexton engelska ord, fyra hemliga grupper. Klockan startar när du trycker.

Misstag kvar 0:00

Så spelar du
  1. Hitta fyra grupper med fyra ord som hör ihop. Markera fyra ord och tryck Gissa.
  2. Se upp för ord som verkar passa i flera grupper. Bara en lösning går ihop.
  3. Grupperna blir svårare från gul till lila. Fyra bom och spelet är slut.
  4. Färre misstag vinner, och tiden avgör vid lika. Guld vid 0 misstag, silver vid 1, brons vid 2–3.

Bara ditt första försök på dagens rutnät räknas.
